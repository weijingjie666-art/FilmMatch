# FilmMatch 产品概览

> 文档版本：2026-08-02｜对应公开 MVP

## 1. 产品定位

FilmMatch 是一款面向胶片新手的结构化选购决策工具。用户通过约 3 分钟完成偏好测评，即可获得 Top 3 胶片相机、第一卷胶片、首次体验总成本、主要风险和验机重点。

**核心价值：把模糊偏好翻译成可解释、可比较、可执行的第一套胶片装备方案。**

公开体验地址：[FilmMatch 公开 MVP](https://filmmatch-public-mvp.weijingjie666.chatgpt.site/)

## 2. 用户问题

胶片新手在做选购决策时，常常同时面临以下问题：

- 型号、参数和分类过多，不知道应该先选自动、半自动还是机械手动；
- 博主、卖家和论坛的信息零散，难以判断哪些建议适合自己；
- 二手价格、成色、故障风险和验机要点难以同时评估；
- 容易只考虑机身价格，忽略胶卷、冲洗、扫描、电池和维修预留；
- 选完相机后，仍不知道第一卷胶片怎么选、怎么拍。

## 3. 与通用大模型的差异

通用大模型可以回答胶片问题，但用户需要自己组织需求、补充条件、反复追问并判断信息。FilmMatch 提前设计好完整决策过程：

| 决策环节 | 直接问通用大模型 | FilmMatch |
| --- | --- | --- |
| 需求收集 | 用户需要知道该说什么 | 11 项偏好引导关键条件 |
| 推荐稳定性 | 受对话上下文和表述影响 | 同一条件下可复现 |
| 推荐依据 | 用户还需继续核对 | 基于结构化相机/胶卷数据和明确规则 |
| 输出 | 多为文字建议或型号清单 | Top 3、首卷胶片、成本、短板和验机重点 |
| 后续行动 | 用户自行搜索、比较和记录 | 继续承接对比、收藏、百科和拍摄计划 |

## 4. 目标用户

- **低风险纪念型**：希望记录旅行、朋友、家人和重要时刻，关注简单操作和成片成功率；
- **色彩复古型**：关注胶卷色彩、颗粒和样片，希望比较不同风格；
- **预算谨慎型**：会同时评估机身、胶卷、冲扫和维修成本；
- **轻度流失型**：买过胶片设备但使用率低，需要拍摄主题、计划和反馈提醒。

## 5. 核心使用路径

```text
进入首页 → 完成测评 → 查看 Top 3 推荐
→ 查看相机 + 首卷胶片方案 → 计算完整成本
→ 查看详情/对比/收藏 → 保存拍摄计划 → 提交反馈
```

## 7. 核心功能

- 11 项偏好测评；
- 可解释的 Top 3 相机推荐；
- 相机 + 第一卷胶片组合方案；
- 首次体验成本计算与三机对比；
- 相机库、菲林百科和场景指南；
- 收藏、历史、对比和拍摄计划。

## 8. 个人贡献

本项目由项目发起人独立完成核心工作：用户研究、数据整理、推荐规则设计、产品原型与开发、小红书冷启动、用户回复、反馈归纳和产品迭代。AI 用于辅助开发、资料整理和内容生产；产品判断、数据审核与最终决策由人工负责。

## 9. 当前边界

- 价格是二手市场参考区间，不是实时库存或成交价；
- 匹配分代表偏好契合度，不是相机绝对质量分或购买保证；
- 收藏、历史和计划主要保存在当前浏览器；
- 站内完整漏斗尚未正式采集，当前展示的是小红书冷启动数据和未来埋点方案。

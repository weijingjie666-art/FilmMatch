# FilmMatch 推荐逻辑

> 规则版本：`rule_v0.2`｜文档更新：2026-08-02

## 1. 设计原则

FilmMatch 使用可解释的规则推荐引擎，而不是让大模型临时生成相机型号。规则与相机/胶卷数据分离，便于根据用户反馈调整权重、标签、阈值和排除条件。

系统需要做的不是选出“最好的相机”，而是在当前用户条件下给出更合适、风险更透明的候选集。

## 2. 输入与用途

站内测评共包含 11 项偏好：

| 输入 | 主要用途 |
| --- | --- |
| 预算上限 | 相机硬筛选 + 预算契合度 |
| 操作偏好 | 自动/半自动/手动适配 |
| 便携性要求 | 根据机身重量与类型评分 |
| 新手友好度 | 学习成本与自动化程度适配 |
| 主要拍摄场景 | 相机场景匹配 + 胶卷取向 |
| 主要拍人/拍景 | 胶卷题材适配 |
| 颗粒感/清晰感 | 胶卷风格适配 |
| 主要光线 | ISO、宽容度和使用风险判断 |
| 使用场合 | 胶卷与拍摄建议场景化 |
| 维护风险接受度 | 相机硬筛选 + 维护契合度 |
| 是否已有相机 | 完整成本与使用建议 |

其中，相机匹配分使用 6 个维度：预算、操作、场景、便携、新手友好和维护风险。其他偏好主要用于首卷胶片和拍摄建议，不会被包装成相机绝对质量分。

## 3. 候选池硬筛选

在计算排名前，系统会排除明显不符合条件的型号。当前公开 MVP 的主要口径包括：

- 价格下限高于用户预算的容差上限（当前页面口径为预算 × 1.2）；
- 维护风险明显超过用户接受范围（当前页面口径为接受度 + 1）；
- 综合分低于推荐阈值（当前页面口径为 3/5）；
- 相机类型、镜头结构或关键规格与用户需求存在明显冲突。

被排除的型号不是“差相机”，而是不适合当前条件。页面会展示部分排除原因，让用户理解为什么没有进入 Top 3。

## 4. 相机匹配评分

```text
综合匹配分 = 预算匹配 × 16%
           + 操作适配 × 12%
           + 场景适配 × 45%
           + 便携性   × 10%
           + 新手友好 ×  8%
           + 维护风险 ×  9%
```

场景权重最高，因为 FilmMatch 优先回答“用户想拍什么”，而不是只按参数或热度排名。场景子分会区分宽泛场景与具体用途：命中核心场景时加权，未命中用户的主要场景时降低排名，同时覆盖多个目标场景的型号优先。

## 5. 排名与解释

候选机按综合匹配分排名，输出 Top 3，同时生成：

- 推荐层级与匹配度；
- 推荐理由和最适合场景；
- 主要短板、常见风险和验机重点；
- 替代型号；
- 预算、操作、场景、便携、新手、维护六维子分。

**匹配分只表示当前偏好与纸面数据的契合度，不代表相机质量，也不代表购买成功率。**

## 6. 首卷胶片选择

胶卷与相机分开判断。首卷方案综合考虑：

- 拍摄对象与使用场合；
- 主要光线、ISO 和快门余量；
- 颗粒、清晰度、色彩和肤色偏好；
- 用户经验和曝光失败风险；
- 购买便利度、参考价格和冲扫便利度；
- 是否已经拥有相机。

对第一卷用户，规则优先降低失败风险。例如在阴天、日常和人像场景下，ISO 400 彩色负片通常比低感光度反转片更容易作为稳定起点。

## 7. 成本口径

首次体验成本不只包含机身，而是根据实际情况组合下列项目：

```text
机身 + 镜头 + 电池 + 胶卷 + 冲洗 + 扫描
+ 邮费 + 密封更换 + 维修预留
```

固定镜头相机不重复计算镜头。未录入的费用应显式提示，而不是填入伪精确值。

## 8. 数据质量与迭代

每次调整推荐规则时，至少应检查：

- 相近用户输入是否真的需要产生差异；
- 固定镜头/可换镜头、卡口、重量和价格字段是否一致；
- 新手首卷是否因低宽容度、低 ISO 或复杂冲洗带来不必要风险；
- 推荐理由、排除原因和成本是否与底层字段一致；
- 用户反馈是触发单个案例修正，还是规则或数据结构修正。

对权重、阈值和硬筛选的变更应同步记录在 [iteration-log.md](iteration-log.md) 中。

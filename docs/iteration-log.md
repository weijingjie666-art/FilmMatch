# FilmMatch 迭代日志

> 记录原则：只写已发生的调研、产品和运营动作；未实现内容单独放在 Roadmap。

## 2026-07｜从真实问题到 MVP

### 问题确定

- 从胶片新手在型号、二手风险、完整成本和首卷胶片上的选择困难出发；
- 将产品定位收敛为“帮胶片新手选对第一套装备”；
- 确定首期不做实时交易、成色担保和成熟社区。

### 用户研究

- 设计 24 题探索性问卷；
- 回收 15 份有效样本，用于形成用户画像和 MVP 假设；
- 根据预算、操作门槛、场景、视觉偏好、二手风险和冲扫成本设计输入维度。

### 第一版产品

- 整理相机、胶卷、价格、风险和资料来源字段；
- 设计预算、操作、场景、便携、新手友好和维护风险六维评分；
- 上线偏好测评、Top 3、首卷胶片、成本计算、三机对比、收藏与历史等核心路径。

## 2026-07 下旬｜内容冷启动与人工跑测

### 冷启动动作

- 创建小红书专属账号、头像、名片背景和 `#FilmMatch` 词条；
- 通过“评论区交卷，我帮你跑结果”的方式降低测试门槛；
- 为首批用户输出“Top 3 相机 + 第一卷胶片 + 成本 + 风险 + 验机重点”；
- 完成 25 份结构化详细回复，并将回复模板沉淀为服务 SOP。

### 阶段性结果

截至 2026-08-02 14:40：最高单篇 1144 浏览、59 赞、21 收藏、78 条评论区互动；收到 3 条对工具感兴趣的私信，新增粉丝 20+；`#FilmMatch` 累计 1333 浏览、96 讨论。

这些是内容冷启动数据，不冒充站内留存或付费转化数据。

## 反馈驱动的已完成迭代

| 真实问题 | 产品发现 | 已完成动作 |
| --- | --- | --- |
| 相近选项得到的候选机过于相似 | 数据量和标签颗粒度不足 | 扩展相机库，重新检查场景权重和标签 |
| 评论区问题少于站内测评 | 轻问卷利于获客，但无法表达完整场景和风险偏好 | 保留 6 题轻测评用于评论区互动，站内扩展为 11 项偏好 |
| 新手首卷曾出现 Velvia 50 | 反转片的宽容度与新手低风险目标冲突 | 重新校准经验、光线和失败容忍度，新手优先 C200/C400/UltraMAX 400 等更稳妥方案 |
| 部分固定镜头便携机的结构字段不一致 | 相机结构、卡口和成本字段会连锁影响结果 | 检查固定/可换镜头字段约束，避免重复计算镜头成本 |
| 匹配分容易被理解为质量分 | 用户可能把高分理解为机况担保 | 在结果页和回复中统一补充“匹配分不代表质量或购买成功率” |
| 二手实际机况可能与纸面排名冲突 | 测试视频、维修记录和退换条件对购买更重要 | 增加常见故障、验机重点和“机况优先”提示 |
| 逐一回复耗时且表达不一致 | 人工服务可验证需求，但难稳定复制 | 沉淀 Top 3、首卷胶片、成本、风险和追问反馈的统一 SOP |

## 2026-08-02｜公开 MVP 快照

经公开页面检查，当前版本已包含：

- 500 台胶片相机；
- 35 款胶卷；
- 41 条场景化选卷指南；
- 46 篇菲林百科；
- `rule_v0.2` 推荐运行口径；
- 11 项偏好测评、Top 3、首卷胶片、完整成本、三机对比、收藏、历史和拍摄计划。

## Roadmap

### P0｜下一阶段验证

- 接入真实站内埋点，区分内容数据和产品漏斗数据；
- 建立测评完成率、详情点击率、收藏/对比使用率和反馈提交率基线；
- 持续校验价格、机身结构、重量、卡口和风险字段；
- 增加推荐满意度、未购买原因和最终选择的结构化反馈。

### P1｜购买后闭环

- 拍摄记录和任务；
- 冲扫结果复盘；
- 下一卷胶片推荐；
- 7 日回访与重新推荐。

### P2｜数据和服务升级

- 更稳定的价格更新机制；
- 账号和跨设备同步；
- 基于真实反馈优化权重和标签；
- 使用大模型作为解释和追问层，不取代结构化数据与规则层。

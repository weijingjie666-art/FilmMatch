# FilmMatch 用户研究

> 本文档仅保留汇总数据和脱敏结论，不包含真实姓名、头像、微信号、私信原文或聊天截图。

## 1. 研究目标

在开发 MVP 前，研究重点不是证明“所有胶片用户都需要 FilmMatch”，而是确认：

- 胶片新手最难的决策环节是什么；
- 哪些输入真正影响相机和胶卷选择；
- 用户愿意为第一次完整胶片体验支付多少；
- 用户对手动操作、二手风险和拍摄失败的容忍度；
- 哪种结果形式能真正帮助用户做决策。

## 2. 研究方法

| 项目 | 说明 |
| --- | --- |
| 工具 | 24 题探索性问卷 |
| 有效样本 | 15 份 |
| 样本结构 | 约为“从未使用：使用过一次性相机：正在使用 = 1：2：1” |
| 用途 | 形成用户分层、MVP 假设和问题设计 |
| 限制 | 小样本、非随机抽样，不外推至全部胶片用户 |

正式开发后，通过小红书评论区轻测评和追问继续观察需求，并完成首批 25 份结构化详细回复。这 25 份是服务与产品测试样本，不与前期 15 份问卷样本合并为同一统计口径。

## 3. 问卷主题

问卷围绕以下主题展开：

- 当前胶片使用阶段；
- 相机和首次完整体验预算；
- 主要拍人还是拍风景；
- 旅行、日常、家人朋友、生日、毕业等使用场景；
- 颗粒、清晰度、复古感、色彩和肤色偏好；
- 自动、半自动和手动操作接受度；
- 二手相机成色、故障、维修和退换担忧；
- 胶卷、冲洗、扫描和邮费对持续使用的影响；
- 为什么想买、为什么没有购买或为什么停止使用。

## 4. 关键发现

| 研究发现 | 样本内表现 | 产品决策 |
| --- | --- | --- |
| 多数用户仍处于入门阶段 | 3 人尚未真正接触；一次性相机与拍立得经验常见；样本中无单反或旁轴胶片机经验 | 使用新手语言，不要求用户先懂复杂参数 |
| 完整预算偏低 | 15 人中有 12 人的完整体验预算不超过 ¥800 | 预算作为硬筛选，展示机身以外的成本 |
| 用户不追求复杂手动操作 | 全自动与半自动相机偏好各 6 人 | MVP 优先覆盖全自动和易上手半自动相机 |
| 胶片的首要价值是记录 | 旅行 7 人；家人朋友、日常生活、重要事件各 6 人；纪念性记录 8 人 | 推荐围绕场景与关系设计，不只按器材参数分类 |
| 视觉偏好会直接影响选卷 | 6 人偏好明显颗粒和复古感，8 人选卷时关注色彩 | 结果页增加色彩、颗粒、肤色、适用光线和风险说明 |
| 选择与二手风险是主要障碍 | “不知道买哪款”和“难判断二手成色”各 5 人 | Top 3 必须同时显示短板、常见故障和验机重点 |
| 总成本影响购买和留存 | 预算不足 4 人；总成本超预期 3 人 | 建立完整成本计算，不只显示机身价格 |

## 5. 用户分层

### 低风险纪念型

主要记录旅行、朋友、家人和重要时刻，关心操作简单、便携和更稳定的成片率。

### 色彩复古型

关注色彩、颗粒、肤色和风格样片，希望理解不同胶卷在光线和冲扫方式下的差异。

### 预算谨慎型

关心首次投入和长期持续成本，需要明确知道胶卷、冲扫、电池和维修是否会超过预算。

### 轻度流失型

已经拥有设备或拍过少量胶卷，但没有稳定的拍摄习惯，需要场景主题、计划和回访机制。

## 6. 从研究到 MVP

首轮研究将 MVP 优先级收敛为：

1. 场景化相机 + 胶卷组合推荐；
2. 显示“为什么推荐”和“需要注意什么”；
3. 将二手风险和验机重点纳入结果；
4. 计算首次完整体验成本；
5. 用第一卷胶片和拍摄计划承接购买后行动。
